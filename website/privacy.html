Version 2.0.0

No telemetry · no accounts

What it stores, and what it sends.

The suite has no analytics, no crash reporting, no licence server and no update check. Everything it knows about the machine stays on the machine — and this page lists the whole of it.

What it never does

No network feature runs unless you press something that needs it.

No telemetry

No usage counters, no feature pings, no device identifiers. There is no endpoint to send them to.

No accounts

No sign-in, no key, no email address, no activation. The archive runs on an offline machine.

No ads or bundles

No offers, no partner installs, no browser toolbar. The archive contains what the package table says it does.

No background sampling

Meters tick while their page is visible. Close the window and the suite stops reading the machine.

What it writes

Only what a page needs to remember your choices.

WhereWhatWhy
%LOCALAPPDATA%\ZanpharsWinSuite\settings.iniTray options (close, minimise, start in the tray, toast notifications), clean prompts, cleanup ticks and sort order, task rulesSo the suite opens the way you left it
Windows registryOnly the values a page changes, each with its original value and type saved firstSo Revert can put them back exactly
Recycle BinFiles removed by Cleanup's Downloads target and by Large filesSo a mistake is recoverable
%ProgramData%\DNSProtect\The DNS journal and watchdog state, when the standalone program is usedTo restore the previous resolvers
%ProgramData%\SystemTurbo\The power plan and service journal, when the standalone program is usedTo restore the previous profile
%LOCALAPPDATA%\SmartRAM\config.iniThe standalone Smart RAM's automatic clean optionsTo keep its settings between runs

Nothing is written to the suite's own folder, so it can live on a read-only USB stick apart from the settings file above.

What it sends

Two features use the network, and both do exactly one obvious thing.

Latency check

Four ICMP echo requests to the host you type — 1.1.1.1 until you change it — with a one-second timeout each. The replies carry timing only; nothing about your machine is attached.

DNS

Name resolution goes to the resolver you pick, through Windows, exactly as before. The watchdog compares registry values; it does not query the resolver on its own.

This website is static. It carries no analytics of its own, no third-party fonts, no cookies and no tracking pixel; the only script written here is the small file in assets/js that opens the menu and the screenshot viewer. The host that serves these pages counts visits with Cloudflare Web Analytics, a cookie-free beacon the host injects - no identifier is stored on your device and the suite itself never reports anything.

Permissions, in plain words

Administrator rights are asked for once, by the pages that genuinely need them.

  • Standard user: the window, cleanup of your own caches, browser traces, memory cleaning, large files, startup entries for your account.
  • Administrator: DNS, Internet & networking, Game Booster's service changes, Deactivate, Services, and ending another user's process.
  • The task agent: a small window-less executable registered in your own Run key, and only after you save a task rule. Delete the rules and it is unregistered.

Read the code, not just the promise

The suite is BSD 3-Clause and builds from the tree with one batch file.
