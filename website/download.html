Check what you downloaded

The archive ships with its own checksum, and the package ships one for every file. Both are plain text; neither requires the suite to run.

Windows PowerShell

Compare the archive's hash with the published one.

Get-FileHash .\Zanphar-WinSuite-v2.1.0.zip -Algorithm SHA256

Git Bash, WSL or Linux

Checks the archive and, once extracted, every packaged file.

sha256sum -c Zanphar-WinSuite-v2.1.0.zip.sha256
cd Zanphar-WinSuite-v2.1.0
sha256sum -c SHA256SUMS.txt

Requirements

If Windows runs, the suite runs. There is no redistributable to install and no runtime to keep updated.

Operating systemWindows 10 or Windows 11, 64-bit
Architecturex64; the executables are statically linked against the compiler runtime
Disk spaceAbout 12 MB extracted
PrivilegesStandard user for the window; administrator only for the pages that change the machine
NetworkNone required. The latency check uses ICMP to the host you type; DNS uses the resolver you pick
DependenciesNone beyond the DLLs Windows itself provides

First run

Three things are worth knowing before the first click.

SmartScreen

The executables are not signed with a commercial certificate, so Windows may show “Windows protected your PC”. Choose More info, check the publisher line, then Run anyway — or build it from source.

Elevation

Changing DNS, networking, Game Booster, startup entries, services or another user's process needs rights a standard user does not have. The suite says so, offers to restart elevated once, and carries on.

Where settings live

Ticks, sort order, tray options and the clean prompts are kept in %LOCALAPPDATA%\ZanpharsWinSuite\settings.ini. Nothing is written to the registry for its own sake.

Removing it

There is no uninstaller because there is nothing installed. Delete the folder you unzipped, then the settings file above. Changes the suite made are reverted from the page that made them, not by deleting the program.

Put the machine back first. Use Revert all on Internet & networking and Game Booster, Use system DNS on DNS, and Restore all on Deactivate. The journals live next to the settings, so reverting works even after a restart.

Build it from source

The whole suite compiles with MinGW-w64 and one batch file — no Visual Studio, no CMake, no package manager.
