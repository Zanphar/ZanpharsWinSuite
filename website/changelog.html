Version 2.0.0

Release notes

Every change, in order.

The suite is versioned as a bundle; each program keeps its own version in its executable. Dates are the days the change landed.

This page summarises the releases. The complete, line-by-line log is in CHANGES.md.

2.0.0 Current 25 November 2026

Disk maintenance moves into the suite, Internet Connection Utility goes back to being a connection doctor, and the bundled tools carry the fixes made since 0.2.5.

Storage

  • A page for the drives. Every local volume is listed with the media type Windows reports, its free space, and the mode Windows' defragmenter will use: Defragment on a mechanical disk or TRIM on an SSD. A volume whose media type cannot be read shows a disabled Unavailable button instead of a guess.
  • Asks first, then runs on a worker. A per-volume confirmation names the drive, its media and the exact mode before the administrator prompt. While defrag.exe runs, the page disables Refresh and every volume button, shows elapsed time, the reported percentage and a progress bar, and offers Cancel, which terminates the child process. The result (or defrag.exe's last error) is reported on the page.
  • Reachable at every scale. The volume list follows the wheel one row per notch, and its scrollbar thumb can be dragged; row hit-testing is rebuilt after scrolling and dragging, so a press lands on the row under the pointer.

Internet Connection Utility 1.4.0.0

  • Disk work leaves the doctor. The Defragment and TRIM repairs, the storage checks behind them and the disks module are gone; the Storage page now owns both actions. ICU keeps its 19 connection and system repairs.

Also in 2.0.0

  • PCSpeedTest records whether each graphics row was timed on the GPU clock or wall time in a new gpu_timing column, adds a GPU frames row, and gains --empty for scheduled-task cleanup.
  • Internet Tuning Wizard moves the Nagle switch in with the other switches, lets the adapter scrollbar be dragged, and no longer resets switches that were left off.
  • Home Policy ships a catalog drift check after its 37 rows were audited against the installed ADMX files; three descriptions were corrected and tags no longer squeeze the registry path.
  • HardWin carries ticked rows through an elevation restart and draws a tight HW mark in its 16 and 24 px frames.
0.2.5 24 November 2026

Internet Connection Utility learns to look after the drives it is diagnosing, and the suite moves to 0.2.5.

Internet Connection Utility 1.4.0.0

  • Defrag and TRIM in the repair list, not a tenth program. The doctor names every local fixed volume with the media type its device reports and offers Defragment on a mechanical drive and TRIM now on an SSD, so nobody has to guess which maintenance a disk wants.
  • Two new checks. Free-space fragmentation is measured from the NTFS volume bitmap and warns past 25%; on solid-state media the scan reports TRIM support and whether Windows is passing deletes on (DisableDeleteNotify).
  • Documented interfaces only. Defragmentation runs Windows' own defrag.exe /D; TRIM is sent with IOCTL_STORAGE_MANAGE_DATA_SET_ATTRIBUTES for the ranges the file system has already released, so no allocated block is ever hinted as discardable. Both repairs are ADMIN, and the TRIM repair re-enables delete notifications first when Windows had them off.
0.2.4 24 October 2026

Game Booster learns the long list of background services a gaming session does not need, and the notification area becomes somewhere to start the suite and run a memory clean from.

Game Booster

  • Twenty-eight background services, each its own switch. Telemetry, the touch keyboard and handwriting panel, Netlogon, Xbox Live, image acquisition, geolocation, the compatibility assistant, WAP push routing, retail demo, Error Reporting, Print Spooler, certificate propagation, enterprise app management, biometrics, the Insider service, the connection broker, Remote Desktop, the portable device enumerator, Parental Control, Connect Now, smart cards, Windows Event Log, Remote Registry, the phone service, downloaded maps, AllJoyn, Fax and Secondary Logon.
  • Live state on every row. The real service names, their start type and whether they are running, so a row Windows already had off reads Already off and one whose services are not installed says so instead of offering a switch that would do nothing.
  • Stopped and set to Manual, not Disabled, so Windows can still start one when something genuinely asks for it. Start type, running state and the delayed-autostart flag are saved first, and Revert puts each back exactly; Revert all includes the services. Rows Windows leans on print their state in the warning colour, and none of them is part of the one-click profile.

Notification area

  • Show on system tray at startup. A new Settings option opens the suite straight into the tray with no window on the desktop. If the shell refuses the icon the window is shown instead, so it can never run with nothing to click.
  • Regular and Deep Memory Clean in the tray menu, beside Open and Exit. Both run exactly what the Memory page runs, including the Settings prompts and the deep clean's administrator restart, so a clean no longer needs the window opened.
  • Toast notifications, switchable. The balloon that reports a menu-started clean can be turned off for a silent clean; the Memory page still carries the figures. On by default, and a settings file without the key reads as on.

Task Manager

  • Saved rules apply without signing out. Saving a rule starts the helper immediately, so a program launched later in the same session picks up its affinity and priority.
  • Every core is reachable: the affinity chips wrap instead of running off the card, and both Apply buttons stay inside it.
  • One window only. A second launch closes the copy already running, and the page is named Task Manager throughout.

Fixes

  • A ticked task stays with its own process. Windows reuses process ids, so a tick held by the number alone could put a stranger in front of End task. A tick now carries the process creation time and is dropped the moment that process exits.
  • The start-type chips change the whole selection. Automatic, Automatic (delayed), Manual and Disabled now act on every ticked service, skip the ones already in that state, and report how many changed.
  • A hidden suite stops working. Parked in the notification area, the window is hidden rather than minimised, so the page polls kept measuring folders and enumerating processes and services all day. They now run only while a page is on screen.
  • Smaller repairs. Service ticks survive a change of capitals, and the Game Booster list no longer scrolls past its last row into empty space.
0.2.3 24 October 2026

The Recycle Bin joins Cleanup: listed with its real size, emptied only after a warning, and never armed for you.

Cleanup

  • The Recycle Bin is a row of its own. What Windows has already deleted is measured across every drive in one shell call, shown with its size and item count, and marked permanent.
  • Unticked, and never ticked for you. Select all leaves it alone, the row is never written to the saved ticks, and it never comes back armed.
  • One warning before it goes. Clean selected stops at a confirmation that names the size and the item count and says the items are deleted for good. Emptying then reports only what actually left, so an item another program is holding open is counted as left behind rather than as freed.
0.2.2 24 October 2026

A repackage: the latency check finishes itself, CI refuses a binary or a licence naming the wrong holder, and the archive the site hands out is the one in release\.

Internet & networking

  • Before and after in one press. Applying the gaming profile takes the baseline first when there is none, then measures the host again as soon as the values have landed, so the comparison appears without reaching for Measure after. An apply that changed nothing does not ping, and a failed measurement leaves its error on the card without undoing the work.

Release and CI

  • Every packaged executable is checked for its publisher. CI reads the Windows version resource of each .exe in the staged package and fails unless CompanyName is exactly Charles McDonald and the copyright line names him.
  • The packaged licence is checked by content. The same job fails unless the staged LICENSE.md is BSD 3-Clause with the Charles McDonald copyright line, all three clauses intact and no MIT text anywhere.
  • The download matches the release. The archive in release\, the copy on the download page and the SHA-256 printed beside it all carry the same figures.
0.2.1 24 October 2026

Scrollable storage and adapter lists, tick-box multi-select across Services and Task Manager, fully controllable Game Booster rows, a measured latency check, and a release step that refuses to publish a muddled folder.

Internet & networking

  • A new page for gaming latency with four settings, each with its own switch: Nagle's algorithm off on every configured adapter, network throttling and system responsiveness off, the Games multimedia task profile, and no QoS reservation.
  • Apply profile and Revert all work over the same journal as the rows, so a set can go on or come off in one press.
  • A latency check that pings any host or IPv4 address four times on a worker thread, reports average, min–max and packet loss, and compares the before and after readings in milliseconds.
  • The comparison comes with the profile. Applying the profile with no reading yet measures the baseline before the values change, and applying it with one in hand measures the host again once they land — the after-reading is taken automatically, so the before-and-after appears without a second press.

Game Booster

  • Every row is controllable. A value that was already set by something else used to read Set elsewhere; it can now be turned off, with its original data and type journalled so Revert restores exactly what the other tool had set.
  • System Turbo's profile remains the first row, followed by Game Mode, mouse acceleration, fullscreen optimisations, window animations and transparency.

Cleanup

  • Downloads goes to the Recycle Bin, and cleaning a personal target asks first, naming the file count.
  • Measured as the page opens, with per-row progress instead of one Scanning label, and a Cancel that leaves unreached rows dimmed rather than empty.
  • Remembered choices: ticks, the biggest-first or built-in order, and Select all, Clear all and Reset to defaults alongside them.

Services, Task Manager and DNS

  • Tick boxes for bulk actions on Services and Task Manager: Start, Stop, End task and Force end act on every ticked row that needs it, with one prompt and one summary.
  • Search boxes narrow either list by name as you type.
  • Services editing — New, Edit and Delete for non-Windows entries — and the four start types as chips.
  • Task rules keep affinity and priority per program and apply them on later runs through a small agent registered only when a rule is saved.
  • Every adapter on the DNS page is reachable: the list scrolls a whole card per notch and shows a position bar and count.

Settings and release

  • Close to system tray and Minimize to system tray, both off until chosen and remembered.
  • The two clean prompts can be switched off, and the BSD 3-Clause agreement opens read-only with the copyright line.
  • One package per release folder, enforced by the release step and by CI, with the packaged README, CHANGES and LICENSE checked byte for byte against the repository.
0.2.0 22 October 2026

The release pipeline arrived: bin\ can be turned into a versioned, verifiable archive in one step.

  • release.bat reads the version from VERSION, rebuilds from scratch with /build, stages every executable with the three documents, and writes the archive plus its checksum.
  • MANIFEST.txt lists each program's product name, version, size, description, publisher and SHA-256, read from the executable's own version resource.
  • SHA256SUMS.txt is sha256sum -c compatible, with LF-only line endings and forward-slash ZIP entries so archives extract correctly on every platform.
  • A failed packaging run no longer leaves a truncated archive next to the good one.
0.1.0 22 October 2026

The first packaged release: the suite window and its four engines build from one script into bin\, with the shared dark, DPI-aware interface and the journaled Revert behaviour that every page still uses.

Known limitation. Releases are not byte-for-byte reproducible: the archive stores file timestamps, so rebuilding the same sources yields a different ZIP digest. Rebuild and re-release rather than comparing archive hashes.
